2. Funcionamiento de la aplicación

Voley Andalucía permite consultar información deportiva sobre competiciones, equipos, partidos y clasificaciones.

3. Información y datos

La aplicación no requiere crear una cuenta de usuario para consultar la información deportiva.

Puede almacenar preferencias, como el equipo favorito, en el dispositivo.

Para consultar información actualizada, la aplicación realiza conexiones a servicios externos. Estas conexiones pueden implicar el tratamiento técnico de direcciones IP y otros datos necesarios para la comunicación.

4. Servicios externos

La aplicación consulta fuentes externas de información deportiva y puede abrir aplicaciones de mapas para mostrar ubicaciones. El tratamiento de datos por dichos servicios está sujeto a sus propias políticas de privacidad.

5. Conservación y derechos

Las preferencias locales pueden eliminarse mediante las opciones del dispositivo o desinstalando la aplicación, según el sistema.

Para consultas sobre privacidad o el ejercicio de derechos de protección de datos, puedes contactar con el responsable mediante el correo indicado anteriormente.

6. Cambios en esta política

Esta política podrá actualizarse cuando cambien las funcionalidades o los servicios utilizados.
